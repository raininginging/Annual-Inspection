# Annual Inspection

手机端 Housing NB 年度单元巡检表。界面按 `template.docx` 的栏目填写，记录存在本机浏览器，导出时把勾选和备注写回原 Word 模板。

打开：

https://raininginging.github.io/Annual-Inspection/

如果页面打不开，到仓库 Settings → Pages，Source 选 `main` / root，保存后再打开上面的地址。

## 用法

1. 用手机浏览器打开上面的地址。
2. 新建一条记录，按表填写。Good / Fair / Repair 会在 Word 对应格子里打 `X`，YES/NO 会标成 `[X]`。
3. 保存只存在这台设备。换手机前先导出 JSON，到新设备再导入。
4. 导出 Word 需要能读到同目录的 `template.docx`。Pages 站点可以；直接双击本地 html 时浏览器会拦截，请用上面的网址。

Replace / Repair 的现场照片请留在手机相册，在 Comments 里写位置。这张表不把照片嵌进 Word。
